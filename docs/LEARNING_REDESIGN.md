# Vocab：一次开始，自动学会下一步

2026-09-06 · 核心算法与交互统一设计

这是统一的目标方案。Android 核心闭环已按它重构源码，实际覆盖范围、取舍及待验证项见 [本轮交付说明](ANDROID_REFACTOR_STATUS.md)。配套的 [交互原型](prototype/index.html) 使用演示数据，可离线打开；用于验证操作流程，不计算真实记忆概率。

## 1. 产品只承诺一件事

**用户只管开始、认真回忆、如实反馈；系统负责教什么、怎么练、何时再见、今天学多少。**

“简单”指少做决策、少配置、少等待，不是免除主动回忆。效果目标是：在可持续的时间投入下，隔一段时间、换一个语境，仍然看得懂、用得出。

系统应保证正确的学习流程与可核查的证据，不能保证所有人在任意投入下都不遗忘。默认体验必须包含教学、提取、纠错、间隔和验证，而非要求用户自行找到正确模式。

## 2. 从材料中保留什么，纠正什么

参考了根目录和仓库中的 `session.md`、`interations.md`、`DEVELOPMENT_GUIDE.md`，仓库的 README、PLAN、IMPLEMENTATION_AUDIT、最近六次提交，以及 `../vocab-dual-dim` 的说明和调度/反馈脚本。历史会话以目录里保存的文本为依据；没有假定可访问其他未提供会话。原讨论提出的候选想法不全部升级成必做功能。

| 来源 | 值得保留 | 本次收敛 |
|---|---|---|
| session.md | 词义与用法为单位；理解、产出独立；错后修复；换语境与延迟验证 | 生命周期是按需动作，不是每个词必须走完的十几道关卡 |
| interations.md | 开始学习的单一入口；教学、提取、辨析与迁移 | 六种交互原语归入同一题流，不做六个模式菜单 |
| DEVELOPMENT_GUIDE.md | 本地确定性引擎、AI 材料边界、离线、义项覆盖 | 保留原则，默认设置与学习路径交给系统 |
| vocab-dual-dim | 双维、复习优先、短反馈、跳过不扣进度 | 不照搬固定间隔表、等级加减和 90 天毕业 |
| Android 0.3–0.7 | 本地数据、连续调度、语料缓存、翻卡、自动推进、备份 | 合并重复入口，补齐证据采集，解除多套“掌握”定义的耦合 |

当前源码的具体问题：

| 位置 | 当前行为 | 影响 |
|---|---|---|
| MainActivity.kt / TodayScreen | 三个开始入口，维度、交互、数量、风格同时可选 | 每次学之前要自己设计学习策略 |
| MainActivity.kt / StudyScreen；AppViewModel.selfGrade | 翻面状态仅在 UI；自评不读取翻面/提示历史；“困难”模拟成一次提示 | 看答案后的熟悉感和独立回忆难以区分 |
| ReviewScheduler.kt | 答题超过 20 秒统一降分；答对但有提示仍可增加稳定度 | 阅读长度、打字、切后台可被误算为记忆差；辅助回忆可能抬高独立能力 |
| ReviewScheduler.kt | 新材料即增加 distinctMaterials，包括答错 | 展示新材料不等于在新材料中成功 |
| GraduationPolicy.kt；VocabRepository.checkGraduation | 三维 + 85% + 30 天稳定度 + 创建满 90 天 + 看过三份材料 | 把时间、展示量与成功证据混用；标记 MASTERED 后该方法不重新评估 |
| VocabRepository.queue / dailyQueue | 一次性取候选；新维度也算新项目；只有相邻避让 | 未区分新义项教学与旧义项补练，也没有依据刚答的结果插入修复 |
| VocabRepository.grade | 尝试与进度分别写入；Attempt 未绑定本题材料 | 中断一致性和按语境回溯不足 |
| README / PLAN / IMPLEMENTATION_AUDIT | 不同版本描述并存，部分已过时 | 文档中的功能与真实 UI 不一致 |

“已掌握后仍参与复习”在 Android 的候选查询中是存在的；问题是状态标签不会随遗忘重新计算，不能误写成整个 Android 复习已停止。

## 3. 只保留两条能力，以及三层职责

### 3.1 学什么：一个义项及其核心用法

内部：`Word → Sense → Pattern / Material`。调度主键：`(senseId, C 或 P)`。

- **C，看得懂**：在足够清楚的语境中理解这个义项。
- **P，用得出**：不展示目标英文，能想到并在目标搭配或句型里使用。
- 单独英文回忆中文是 C 的辅助练习，不再维护第三条记忆曲线。脱离语境无法判断多义词时，应接受目标范围内的合理含义，或加上语境。
- 拼写、搭配、辨析、跨场景表现是证据标签或待修复问题，不增加独立总分和毕业关卡。
- C 的成功只更新 C；P 的成功只更新 P。首版不做跨维增益，避免未测即过。
- P 初期只表示受约束的目标表达能力。填一个词正确不自动等价于自由会话、发音或听力掌握。

每道题另外声明证据范围：词形提取、搭配补全或语境理解。比如 `depend ____ the weather` 只检查介词搭配，不能证明用户主动想起了 depend。它可以触发 P 的用法修复，但不能替代隐藏词形的产出验证；原型专门保留这两种短输入以展示差别。

例如 `charge` 的“收费”“指控”“电荷”有不同的 senseId；`charge someone with something` 是“指控”义项的核心模式。一个模式反复出错时安排专项修复，不建立第三套重复复习日历。

### 3.2 何时复习：一个记忆引擎

新目标采用 **FSRS 作为唯一的长期间隔引擎**，经版本固定和官方样例对照后接入。每条 C/P 记录有独立状态。维护稳定度 S、难度 D、上次复习和到期时间；当前可提取概率 R 按时间推导，不再另造一个累加的 mastery 百分比。

FSRS 的 S/D/R 定义和评分接口参考 [官方算法说明](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)。它负责记忆排程，不负责判定语义正确、词义覆盖或真实运用；本项目的双维拆分与动态题面仍需要自己的验证。

内部目标回忆率初始取 0.90，两维相同；P 更难的事实由实际失败与复习历史体现，不再额外统一乘 0.8。0.90 是调度参数，不能展示为“你保证记住 90%”。暂不提供普通用户调参页面，不自动训练缺乏数据的个人参数。

删除目标方案中的固定 1/3/7/15/30 表、L0–L5、独立累加掌握分和满 90 天毕业。迁移完成前，旧引擎可以作为明确标记的兼容实现；同一条记录一次只能由一个版本的引擎更新，不能叠加两套间隔。

### 3.3 这次怎么练：一套明确的决策规则

学习策略读取到期、最近错误、证据缺口和剩余时间，选择下一道动作。AI 不参与排期。

| 当前情况 | 下一步 |
|---|---|
| 从未引入此义项 | 一张简短教学卡：一个意思、一个核心搭配、一个自然例句 |
| C 尚无一次独立成功 | 用较简单的新语境确认理解；必要时先降低句子难度 |
| C 有独立成功，P 未练 | 隔开其他词后，安排一次不展示目标词的短产出 |
| 某一维到期 | 复习该维；两维都到期则先更逾期的一维，另一维避开答案刚暴露的时段 |
| 搭配、词义或近义词混淆 | 一句针对性解释，随后安排对应修复任务 |
| 自评好，但缺少实际作答 | 在该维下次到期时换成选择或短输入验证 |
| 已多次稳定，缺少迁移证据 | 下次到期换场景或句型验证，不额外追加一整轮考试 |

## 4. 每天的算法：按时间收敛，不追求清空

用户唯一的常用设置是每天 **5 / 10 / 15 分钟**，默认 10 分钟。到时间后不再发新题，允许答完当前题；可随时收工并保存。用户选择的是大致投入，不是倒计时考试。

以下都是待验证的产品默认值，不是记忆科学得出的最优常数：

| 参数 | 初始规则 |
|---|---|
| 单轮长度 | 最多 5 个学习动作；结束可继续至今日预算或收工 |
| 新义项上限 | 每日分别不超过 2 / 3 / 5 个（对应 5 / 10 / 15 分钟） |
| 复习负担 | 已到期及必要修复的预计时间达到剩余预算时，新义项额度为 0 |
| 预留修复 | 剩余预算的约 20%；无修复时供到期复习使用 |
| 同词避让 | 按 lemma 避让，不仅按 senseId；暴露答案后至少隔 3 个其他词动作且经过 2 分钟 |
| 当轮错题回访 | 每义项最多 1 次；仍失败则再教一下并安排后续复习 |
| 客观抽查 | 连续最多 4 次自评后，下一个具备合格题面的复习动作自动用选择/短输入；计数跨会话保存 |
| 材料不足 | 可以用旧题维持练习；标记熟悉题，不增加新语境证据 |

预算计算使用近期同类动作的前台活跃用时中位数；无记录时采用保守估计（翻卡 20 秒、选择 25 秒、短输入 35 秒、教学 40 秒），限幅防止离开屏幕污染估计。用时只控制负担，不判记忆好坏。

选择顺序是可解释的优先级，而不是把十几个未经验证的权重相加：

1. 从有合格材料、未暂停的义项生成候选，读取持久化会话和避让信息。
2. 为到期复习预留预算；满足冷却条件的近期修复可以插入，受上面的重试次数和修复时间约束。
3. 到期项目按 `max(0, now - dueAt) / max(lastInterval, 1天)` 降序，再按最久未复习、目标义项优先级、稳定 ID 排序。只有一个实际记忆排程。
4. 对已引入但尚未练过的能力安排首次检查；这不再计作“新词”。
5. 有剩余容量才引入新义项，同时预留教学后首次理解/产出的成本；若最近三次完成日的活跃时间都超预算 20%，下一日上限减一，连续三次不超预算再恢复一级。
6. 选择具体题面时，把缺少客观验证或迁移的任务作为本次题型，不重复新建复习项。
7. 短轮结束就给出收工机会；预算用完不要求清空剩余到期数。未处理项目保留原到期时间，不伪造“已复习”。

新词紧缩可以减缓未来负担，但不能令已有积压自动消失。没有用户加时，系统应维持合理的每日工作量，首页写“今天先巩固旧内容”；不得把未处理任务隐藏成“全部完成”。长期只有一个词可练、或不足以满足同词避让时，结束本轮并安排下次，不用反复同词填满配额。

“再练一轮”仍可用：正常优先到期项，无到期时提供自愿练习。每次真实作答都按实际时间记录；临时加练、同日熟悉题不计为延迟/新语境验证，不通过反复开始刷新每日额度。

## 5. 一道题的闭环：先想，再核对，最后记录

```text
选择义项与能力 → 选择材料 → 回忆/作答 → 简短反馈
                                            ↓
                  原子保存尝试、证据、调度与会话位置
                                            ↓
                          需要修复就标记 → 下一题或收工
```

### 5.1 默认翻卡，明确回忆发生在什么时候

正面只有一道任务，下方是「核对答案」，辅助动作是「想不起来」「提示」。要求先在心里或口头作答；按“核对答案”只表示准备对照，并不能证明已回忆正确。

背面用短答案和一个必要说明核对，再提供三种自评：

- **没想起** → Again。
- **费劲想起** → Hard，仅适用于看答案前独立想起、没有内容提示。
- **独立想起** → Good，仅适用于看答案前已经想起。

不提供 Easy 按钮；没必要让用户学四级评分。点击评分立即保存并进入下一题；答错或使用提示时，先呈现修复说明，由“继续”推进。允许撤销最近一次评分；撤销需原子恢复对应调度、证据及会话变化。

提示后再答对仍记录辅助成功，但独立回忆排程按 Again 处理，不能选 Hard/Good。直接“想不起来”与先看到答案后才懂，都不能算成功。“核对答案”本身不是失败：自评翻卡必须保留 `SELF_REPORTED` 标记，不能假装成客观验证。

### 5.2 系统自动穿插客观题，减少自评错觉

- C：一个充分语境 + 少量含义选项；错误选项必须可排除，猜测可点“不确定”。选择题只证明此情境的辨认，不声称测到主动产出。
- P：隐藏目标词、音标及泄题搭配，填写一个词或短语；接受经题目审核的变形和同义表达。
- 正确答案在提交后才出现。正确作答且未提示、未提前展示答案，才获得 `OBSERVED` 证据。
- “不确定”不能被强行记成完全不会，也不能算强证据。答对但不确定按 Hard 排期，标记 `UNCERTAIN`，不满足稳定验证门槛。
- 用户可以跳过输入题；不扣进度，验证缺口保留。手动打开词库查看本题答案也算暴露；切后台仅记中断，不凭猜测扣分。
- 默认不做长篇造句。达到一定熟悉度后，在正常复习中用短句补全测试关键搭配；自由表达作为扩展，待判分可靠后再加入。

### 5.3 错误处理不需要用户填写诊断表

| 证据 | 即时反馈 | 后续动作 |
|---|---|---|
| 忘记目标表达 | 释义 + 一条核心搭配 | 冷却后换题再提取一次 |
| 错选另一义项 | 并列两个含义与各自搭配 | 下次用能消歧的语境 |
| 单词对、介词/搭配错 | 只指出关键结构，如 depend **on** | 安排一个短语补全 |
| 另一个表达也合理 | “表达成立，这次再试目标表达” | 不标英语错误，不给目标 P 成功；安排不含歧义的目标检查 |
| 疑似拼写失误 | 展示差异，允许修正或标记误触 | 不自动宽松判 Good；修正成功为辅助证据，长期记录保留原答 |
| 句子太难或题目有问题 | 展示解释，允许“一题有问题” | 本题不更新记忆，换简化语境；题目隔离待复核 |

客观判分优先使用结构化答案列表和简单规范化。不能可靠判定时显示参考并改为自评，不让网络等待卡住流程，也不把 AI 的犹豫算成用户不会。经核实无效的题目应撤销其评分影响并从后续有效日志重放，不仅从题库删除。

## 6. 什么才算“比较稳了”

只显示“待学 / 学习中 / 较稳 / 待巩固”，不展示三个百分比或永久毕业。

记忆排程和学习证据各回答不同问题：排程决定何时再来；证据决定是否支持“换语境也能做对”。材料出现次数只用于去重，绝不用于判掌握。

初版“较稳”规则（产品启发式，需以后用延迟检查验证）：

1. C 和 P 各有至少 3 次合格成功，分布在至少 3 个本地学习日；每维每天最多计 1 次。
2. 每维合格成功都要求客观作答、无提示、无提前答案、非猜测，并且距该义项任何答案/教学暴露至少 20 小时。同日修复不算，即使跨午夜也不算。
3. 每维至少覆盖 2 个语义上不同的语境族，不是只换人名、风格标签或标点；不确定的语境族归为未知，不能算新增。
4. 每维至少 1 次合格成功距该义项上次内容暴露至少 7 天；P 的证据里至少一次隐藏目标词形的主动提取，且至少一次涉及核心搭配/结构。给出 depend 后只补出 on，不能单独满足完整 P 验证。
5. 两维最近一次实际回忆结果不能是失败、辅助成功或不确定；当前排程均未到期，无尚未解决的关键用法错误。

这些检查从 Attempt 与 Exposure 历史派生，不维护另一个可任意加分的熟练度。到期但未复习变为“待巩固”，保留曾经达标的历史；后续合格回忆可恢复“较稳”。“待巩固”表示需要再检查，不能断言人已经忘了。

纯自评用户可以正常获得复习安排，界面显示“练习中 · 待验证”，不能获得“已客观验证”的结论。旧题也有练习价值；材料不足时可以继续排程，只推迟迁移达标，不阻塞学习。

单词页按目标义项显示“日常目标 2/3 个义项较稳”。用户可展开看到尚未学的义项、来源与目标范围。新义项加入后会更新分母，不改写已学义项记录。高频日常为默认范围，其他义项可按需加入；来源尚不完整时明确标注“已收录范围”，不能声称穷尽全部词义。一个义项初步建立后即可引入下一常用义项，不必等待前者“较稳”。

## 7. AI 的工作：准备好材料，让学习少等一秒

AI 负责候选材料与简短解释。确定性的本地引擎负责身份校验、判分边界、排程、证据和保存。

- 请求只针对即将用到的 senseId、核心模式和能力，提供已有语境族摘要。每次小批补充，不对所有词反复刷新。
- 冷启动随应用附带少量完整、审核过的示例词义和题库；无账号、无 Key 也能开始。额外内容支持离线导入词包。
- 普通用户不用填网址、模型和 Key。自带服务配置收进高级设置；未来若提供托管 AI，需单独明确服务成本，不能假设供应商免费。
- 每个即将复习的义项，目标保有 2–4 个可用未近期重复的题面；触及下限才后台补充。题目合格可复用，无须见一次就丢。
- 批次按预设 token/调用预算执行。初版每批至多 5 个义项，每次学习启动至多 1 批；失败当次不自动循环重试。按 job key 去重，同一设备同批只允许一个在途任务。
- 累计 token 或调用额度到上限停止生成；支持停止自动补充。此时使用缓存，不出现付费墙阻挡已拥有内容。
- 题目必须有稳定 senseId、预期能力、题面、可接受答案、核心模式、解释、语境族、来源、版本和质量状态。
- admission 至少校验结构、义项绑定、答案与题面关系、目标词暴露、字面去重；近似重复与语义歧义需额外质量检查。字符串包含目标词不能证明正确义项，AI 自报“通过”也不能当成可靠证明。
- 新语境优先改变使用场景与表达意图，并保持无关词汇简单；不能为了换语料不断增加句子难度。
- 不把风格筛选作为取题硬约束；偏好的材料不足时退回一般语境。错题解释优先复用已审说明，开放式 AI 反馈按需请求。

## 8. 用户真正看到的界面

底部导航缩成 **今天 / 词库 / 我的**。统计放在“我的”，设置也放这里。

### 今天

```text
今天                              每天 10 分钟

把认识的词，变成用得出的词。
先复习，再学一点新的。

             [ 开始今天的学习 ]

今天已学 0 分钟 · 有 8 个义项建议巩固

               今天   词库   我的
```

不同时显示“日计划 / 新词 / 任意复习”三套入口，不先问模式、风格、配比。已开始时按钮变为“继续学习”；已达预算时显示“今天先到这里”，次要入口“再练一轮”。设置时间不是每天必走步骤。

### 学习页

上方“本轮 2/5 · 随时收工”，中央一张自适应高度题卡，底部主动作。无定时自动跳转。解释默认一句，展开可看用法和为什么此时复习；任何会泄露答案的解释在作答后显示。

P 正面不出现目标词、音标、答案释义中的英文或词条标题；只有表达意图和必要的带空语境。C 可以展示目标词，但隐藏释义。教学卡可以展示全部信息，但“继续”不加掌握分。

退出、来电、后台、进程重启后保留当前题、已暴露信息、提示、剩余预算、待修复、作答保存状态。旋转屏幕不能把一张翻过的卡变回“未暴露”。本轮 5 步用完只展示这一轮的完成，不虚称今天全部到期项清空。

### 本轮结束

只给有用结果：“练习了 4 个义项；2 个表达需要再巩固。”主动作随剩余预算显示“继续一轮”或“今天收工”。不把教学数、尝试数、词数和已掌握数混为一谈。

### 词库

以词条聚合义项，点击展开“看得懂 / 用得出”的文字状态、核心搭配和下次安排。添加入口默认粘贴单词或导入词包；纯单词无可用释义时进入待补充，不编造释义，不要求填写五列格式。

### 我的

首屏只有每日时间、学习记录、内容管理、更多设置。进度强调“延迟后仍答对的义项”和两维的待验证状态；详细历史按需展开。服务设置、生成预算、备份恢复放二级页。

全部文案统一中文；英文仅用于学习内容。按钮至少 48dp，支持系统字号、深色模式、TalkBack。正面答案不留在可访问语义树；反馈不用单独颜色表示。输入法弹出不遮住提交，长题面整页可滚动，避免固定 280dp 卡片造成双重滚动。

## 9. 迁移方案与实现边界

以下为 Android 重构顺序；逐项实现与验证状态以 [本轮交付说明](ANDROID_REFACTOR_STATUS.md) 为准：

1. **先修证据闭环**：新增稳定 Attempt ID、材料与版本、实际题型、证据范围、目标词形是否给出、评分来源、提示、暴露、活跃用时、sessionId、时间/时区、有效状态；引入 Exposure 事件。尝试、排程、证据索引、会话指针一次事务写入，重复点击以 Attempt ID 幂等；失败可重试但不跳题。
2. **统一两维与状态**：保留旧三维原始数据；旧 C 映射 C，旧 P 映射 P，isolated 作为 C 辅助历史归档，不能相加或取最大值。旧记录没有材料/答案暴露信息时标 `LEGACY_UNKNOWN`，不生成虚假的合格证据。
3. **接入单一引擎**：用稳定版本 FSRS 适配器、官方样例与重放测试验收。旧 S/D 的数值尺度不能直接复制为 FSRS。证据不足的旧记录暂沿用旧到期日并标兼容版本；首次新协议的真实复习后初始化新引擎，再切换该记录，原日志保留。旧“MASTERED”改成历史标签，当前状态等待新证据重算。
4. **收拢交互与动态队列**：移除首页模式选择，教学/翻卡/短验证共用会话控制器；保存每日预算和冷却，做错可按约束插入一次回访。
5. **补齐材料与效果验证**：后台库存按需补充、质量与错误隔离、迁移检查。数据库迁移与备份格式一起升级，旧备份导入保留原历史而不是填造缺失证据。

迁移不能破坏已有词条 ID、词义归属、尝试原文、材料、服务配置或备份能力。本次不擅自改变现有备份是否携带密钥的产品行为。目标设计文档应作为下一轮算法/UX 的统一依据；历史文档留档，不能把旧验收记录改写成已实现新方案。

## 10. 必须验证的行为与效果

| 场景 | 验收结果 |
|---|---|
| 空数据、离线、未配置 AI | 能从审核示例进入教学和第一次练习 |
| 今日一键开始 | 不出现题型、维度、风格或配比选择 |
| C 多次答对但 P 未练 | P 不增长，不显示整体较稳 |
| 正面隐藏答案 | 视觉、无障碍、提示、标题中都不泄露 P 答案 |
| 翻面再说“独立想起” | 是自评证据，不是客观验证 |
| 使用提示后答对 | 保存辅助成功，不能成为独立成功或延迟验证 |
| 三份材料看过但答错 | 可计展示量，不计合格语境数 |
| 单词相同、不同义项 | 分开保存、分开排程；按词形避让 |
| 刚看答案后换维答对 | 视作训练，不能作为独立延迟证据 |
| 5 分钟与 50 秒答对 | 不因统一反应阈值扣记忆分；中断时间不算活跃时间 |
| 一轮反复出错 | 每义项最多一次回访，不突破时间预算追着考 |
| 一词可学、无其他题 | 不伪造交错间隔，合理结束 |
| 材料错误或判分不确定 | 不扣记忆，保留待验证，换题仍可学 |
| 已较稳之后再次失败/到期 | 状态重新计算，既往有效历史不抹掉 |
| 新义项入库/目标范围改变 | 正确更新覆盖分母，旧义项不串进度 |
| 双击评分、保存失败、进程重启 | 只记录一次，恢复原题及答案暴露状态 |
| 开始新会话/跨午夜 | 不重置冷却或刷验证天数；每日额度按保存的本地学习日结算 |
| 网络失败、预算耗尽 | 缓存照常复习，不循环重试、不冒充生成成功 |
| 老库/老备份迁移 | 数量、归属、原历史不丢失；缺失证据标未知 |

产品有效性看 **7 天/30 天后无提示的新语境验证结果、每个保持住的义项所耗活跃分钟、C/P 差距、未完成到期负担、AI 消耗**；不以当天正确率、连续打卡或题量替代效果。

这些指标先记录再评估，不宣称方案已证明优于现版。对比时保持学习内容与时间预算相近，使用未练过的合格题面，记录未完成/跳过验证者的比例，避免只统计坚持完成且答得好的人。模型校准需区分自评、选择与短输入来源。

## 11. 原理依据与推导边界

- 重复提取对延迟词汇回忆的价值，参考 [Karpicke & Roediger, 2008，作者实验室全文](https://learninglab.psych.purdue.edu/downloads/2008/2008_Karpicke_Roediger_Science.pdf)。本设计据此保留“先回忆再核对”，不能把这项研究解读成指定题型比例已经被证明最优。
- 间隔与预期保持时间相互关联，参考 [Cepeda 等，2006，分散练习元分析](https://pubmed.ncbi.nlm.nih.gov/16719566/)。它支持关注延迟表现，不支持把某张固定日期表称为所有人的最佳遗忘曲线。
- 记忆状态与间隔计算参考 [FSRS 官方算法文档](https://github.com/open-spaced-repetition/awesome-fsrs/wiki/The-Algorithm)。FSRS 不能替代本项目的题目质量控制和词义迁移验证。

5/10/15 分钟、三次成功、两组语境、20 小时、7 天、客观抽查比例等是本次设计的工程起点；均需以后用实际学习数据校验。核心不变量是：两维独立、先回忆、提示不冒充独立成功、暴露不冒充掌握、长期效果要经过时间和语境的检验。
