# Vocab 交互原型

浏览器打开 `index.html` 即可，保持 `app.js` 和 `style.css` 在同一目录。无需安装依赖、启动服务或配置 AI。

可体验：今天一键开始 → 理解翻卡 → 搭配输入 → 新义项教学 → 含义选择 → 隐藏目标词的短输入 → 本轮总结；也可使用提示、不确定、跳过、报告题目问题、暂停与继续，以及词库/义项详情、每日时间偏好。

演示进度仅保存在浏览器的 `vocab-flow-prototype-v1` 存储项，可在“我的 → 更多设置”重置。如果浏览器限制本地文件存储，会提示改为本次页面内保存。

这是确定的五步脚本，用于评审交互。它不实现 FSRS、真实每日预算、动态错题回访、义项导入、AI 调用、长期间隔验证和数据库迁移。三档时间仅保存偏好；再次体验会使用相同演示题。词库中的“待验证”不会因本轮答对就变成“较稳”。

真正的规则、迁移与验收要求见 [统一设计](../LEARNING_REDESIGN.md)。Android 的 TalkBack、软键盘、系统字号与深色模式适配仍需在实际应用实现时验收。
